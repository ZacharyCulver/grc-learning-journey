# SY0-701 objective 4.4: Security alerting and monitoring

[Security+ index](../README.md) · Domain 4: Security Operations

Original study notes aligned to the public CompTIA SY0-701 V7 blueprint; not official training or exam questions.

## Explain it

Collect relevant telemetry from endpoints, identity, applications, network devices and cloud services into a protected, time-synchronized location. A SIEM correlates events; thresholds, baselines and behavioral analysis turn raw logs into alerts. Tune detections for false positives and false negatives, define severity and escalation, and ensure an alert has an owner and response path. A dashboard is a view, not a substitute for investigation.

Monitor for anomalous logins, privilege changes, blocked traffic, malware and service failure. Alert volume alone is not effectiveness: measure whether important events are detectable, actionable and retained long enough. Protect logs from tampering, restrict access and test that a known event generates the expected signal.

## Apply it

After an administrator grants an unexpected privileged role, correlate identity audit logs, change ticket and subsequent actions; escalate if no approved change exists.

## Active recall

Describe how you would tune a noisy alert without disabling detection of the underlying threat.
