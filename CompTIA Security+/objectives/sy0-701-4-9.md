# SY0-701 objective 4.9: Investigation data sources

[Security+ index](../README.md) · Domain 4: Security Operations

Original study notes aligned to the public CompTIA SY0-701 V7 blueprint; not official training or exam questions.

## Explain it

Different sources answer different questions. Firewall and network logs reveal flows and denials; DNS and proxy logs show destination resolution and web requests; endpoint and OS security logs show processes, files and logons; application logs show transactions; identity logs show token and privilege events. Packet captures offer granular traffic detail but may be unavailable, encrypted or sensitive. Vulnerability scans describe exposure, not necessarily exploitation.

Correlate timestamps, host/user IDs, source/destination and sequence across sources. Preserve originals, note collection method and clock offsets, and distinguish observation from inference. A dashboard or automated report summarizes data but may omit raw detail needed to validate a hypothesis.

## Apply it

Investigate an unusual upload by correlating identity login, endpoint process, proxy request and firewall flow; record the timeline and what evidence would disprove the initial theory.

## Active recall

Which log would you check first for a failed login, a blocked port, an unauthorized database query and a suspicious process?
