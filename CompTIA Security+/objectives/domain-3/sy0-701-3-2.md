# SY0-701 objective 3.2: Securing enterprise infrastructure

[Security+ index](../../README.md) · Domain 3: Security Architecture

Original study notes aligned to the public CompTIA SY0-701 V7 blueprint; not official training or exam questions.

## Explain it

Place controls where traffic and trust boundaries actually exist. A screened subnet separates public-facing services from internal resources; segmentation may be physical or logical through VLANs, subnets and policy. Firewalls enforce permitted paths, IDS detects and IPS can block, and a load balancer distributes requests without necessarily being a security control. Choose secure access methods and protocols for administration, data transfer and remote connectivity.

Consider failure modes and operational tradeoffs: an inline control can stop malicious traffic but can also disrupt service if misconfigured. A VPN protects a connection but does not make a compromised endpoint trustworthy. Wireless deployments need secure authentication and encryption, site surveys, rogue-device detection and attention to coverage. Document data flows and rule owners; validate both allowed business traffic and blocked paths.

## Apply it

A public web service needs a database. Allow only the web tier's required connection to the database tier, block direct internet access to the database, log denials and verify rules with tests.

## Active recall

Sketch an internet-to-web-to-database flow and place a control at each trust boundary. How do IDS and IPS differ in consequence?
