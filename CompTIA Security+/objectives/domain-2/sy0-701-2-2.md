# SY0-701 objective 2.2: Threat vectors and attack surfaces

[Security+ index](../../README.md) · Domain 2: Threats, Vulnerabilities, and Mitigations

Original study notes aligned to the public CompTIA SY0-701 V7 blueprint; not official training or exam questions.

## Explain it

An attack surface is an exposed entry point; a vector is the route used through it. Email, SMS and voice can carry social engineering, including phishing, smishing, vishing, pretexting and business-email compromise. A watering-hole attack compromises a site a target frequents; typosquatting exploits a similar-looking domain. Removable media, malicious files, exposed services, default credentials, unsupported software and insecure third-party connections provide other entry points.

Defenses should match the route: verified out-of-band approval for payment changes, mail authentication and filtering for impersonation, endpoint controls for attachments, least privilege and patching for exposed systems, and vendor access review for supply-chain exposure. User awareness is useful but does not replace technical guardrails.

## Deeper distinctions

Social-engineering labels describe the channel or manipulation. Phishing is a broad deceptive message, spear phishing is targeted, smishing uses SMS, vishing uses voice, and business-email compromise abuses a trusted business identity or workflow. Pretexting establishes a plausible story. A watering hole compromises a destination frequented by a target; typosquatting depends on a confusingly similar name. An embedded image or attachment can be a payload, while the sender identity can be spoofed independently.

Map every vector to **exposure → trust decision → control**. For remote access, inspect exposed ports, identity, device posture and session permissions. For removable media, inspect autorun/execution and data-exfiltration paths. For a vendor integration, inspect credentials, API scope and subcontractor dependencies. Mail filtering can miss a legitimate compromised mailbox; procedural out-of-band verification remains valuable for high-impact requests.

**Decision drill:** An urgent text with a shortened URL asks an employee to re-enter a password. Name the channel, deception and likely credential-exposure path; choose a safe verification channel and post-click response.

## Additional blueprint concepts

Attack delivery can be message-, image-, file-, voice- or removable-media-based; a malicious image need not visibly “look” suspicious to exploit a vulnerable parser. Unsupported software and default credentials are exposed surfaces, while an open port is only useful to an attacker if a reachable service and weakness lie behind it. Client-based access installs local software; agentless access relies on network or API interaction. Either can create vulnerable components or overbroad credentials, so trace the actual software, connection and permissions.

Misinformation is false content whether intentional or not; disinformation is deliberately deceptive. Both may influence users to take unsafe actions. Impersonation can target a brand, a colleague or a vendor, so verify high-impact requests through an independently known channel.

## Apply it

A vendor invoice email changes bank details and urges secrecy. Stop payment, verify via a known phone number, preserve the message, and check whether the mailbox or vendor account was compromised.

## Active recall

Explain the difference between an attack surface and a vector; classify a fake password-reset SMS and a lookalike login domain.
