# SY0-701 objective 4.1: Securing computing resources

[Security+ index](../../README.md) · Domain 4: Security Operations

Original study notes aligned to the public CompTIA SY0-701 V7 blueprint; not official training or exam questions.

## Explain it

A secure baseline defines approved settings, is deployed consistently, and is maintained as threats and software change. Harden workstations, servers, switches, routers, cloud workloads, mobile devices and constrained IoT/OT systems according to their distinct capabilities. For wireless networks, distinguish WPA3 encryption from enterprise authentication using 802.1X/RADIUS; a site survey and heat map help coverage and rogue-AP analysis. MDM supports enrollment, configuration and remote response under the organization's BYOD, COPE or CYOD model.

Application defenses include input validation, secure cookies, code signing, static analysis and sandboxing. Monitoring verifies configuration drift and compromise. A baseline must be tested so it does not break mission services.

## Deeper distinctions

A baseline begins with a known-good configuration, then deployment, validation and drift monitoring. Secure a workstation differently from a router, mobile device, cloud image or industrial controller. Remove unnecessary software, enforce updates and logging, limit administrative access and test business functions. An image can spread one bad setting across every deployment, so version and review the baseline.

For enterprise Wi-Fi, WPA3 addresses wireless link protection while 802.1X with RADIUS authenticates users/devices against a central service. A site survey informs placement and interference; a heat map is evidence about coverage, not a security policy. MDM enforces enrollment, encryption and lost-device action, but BYOD requires attention to personal data and consent. COPE and CYOD describe different ownership and choice models. Application security adds input validation, secure cookie flags, code signing, static analysis and sandboxing. Each addresses a different failure mode.

**Configuration drill:** Propose a baseline for a new cloud VM and a field tablet; state the owner, test, drift signal and rollback for each.

## Additional blueprint concepts

Connection methods change the exposed path: cellular, Wi-Fi and Bluetooth each need appropriate pairing, encryption and management. WPA3 is a wireless security protocol, while RADIUS centralizes authentication/authorization/accounting for enterprise access; do not treat them as interchangeable. A signed application establishes origin/integrity of its signed package under the trust model, but it does not guarantee safe logic. Static analysis identifies potential code issues before execution; sandboxing limits the effect of an untrusted process, subject to isolation strength.

## Apply it

Before issuing mobile devices, set encryption, lock and update policy, approved apps and lost-device response; document how privacy and ownership differ for BYOD versus corporate-owned devices.

## Active recall

Give a baseline for a workstation and a router. Which controls prevent insecure deployment, and which reveal drift?
