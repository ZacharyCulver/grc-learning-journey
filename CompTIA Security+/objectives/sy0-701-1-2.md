# SY0-701 objective 1.2: Fundamental security concepts

[Security+ index](../README.md) · Domain 1: General Security Concepts

These are original study notes aligned to the public CompTIA SY0-701 V7 exam objectives, not official CompTIA training or exam questions.

## Explain it

Confidentiality restricts disclosure; integrity protects accuracy and completeness; availability keeps services usable. Authentication verifies identity, authorization limits actions, and accounting records actions. Non-repudiation requires credible evidence of origin or action; a digital signature can help, whereas encryption alone mainly provides confidentiality. A gap analysis compares current controls with a defined target state.

Zero Trust removes implicit trust based on network location: evaluate identity, device and context, grant least-privilege access, and continually reassess. The **control plane** determines and administers policy; the **data plane** enforces access at the policy enforcement point. Physical measures include guards, badges, fencing, bollards, lighting, sensors, and access vestibules; choose for the actual risk. Deception tools such as honeypots, honeyfiles and honeytokens provide signals when touched, but should not be treated as a substitute for protecting real assets.

Keep the distinctions practical: a hash can detect modification but does not make a file secret; a backup improves recoverability but needs testing to support availability.

## Apply it

An ISSO reviewing a system boundary finds shared admin accounts. Map the issue to accountability and non-repudiation, then propose unique identities, privileged access controls and log review.

## Active recall

Explain CIA and AAA without notes; distinguish the Zero Trust policy decision from the point that enforces it.
