## About This Repository

This repository contains my comprehensive study notes for the **Microsoft SC-900: Security, Compliance, and Identity Fundamentals** certification.

I developed these notes while studying Microsoft's security, identity, compliance, and governance technologies. Although I successfully passed the SC-900 examination, I continued documenting the entire Microsoft Learn curriculum to build a lasting technical reference.

My goal is to make complex cybersecurity concepts accessible while establishing a practical foundation for continued learning in **Governance, Risk, and Compliance (GRC), Information Assurance, and Information System Security Officer (ISSO)** responsibilities.

## Study Guide Organization

The repository follows the four official Microsoft Learn learning paths.

| Section | Topics Covered |
|---|---|
| **01 — Security, Compliance, and Identity Concepts** | Shared responsibility, defense in depth, Zero Trust, encryption, identity, authentication, authorization, and foundational security principles |
| **02 — Microsoft Entra** | Identity and access management, multifactor authentication, Conditional Access, identity governance, Privileged Identity Management, and identity protection |
| **03 — Microsoft Security Solutions** | Microsoft Security Copilot, Azure infrastructure security, Microsoft Defender for Cloud, Microsoft Sentinel, and Microsoft Defender XDR |
| **04 — Microsoft Purview** | Service Trust Portal, privacy principles, Information Protection, Data Loss Prevention, compliance management, auditing, eDiscovery, records management, and data governance |

Each section contains individual Markdown files organized by Microsoft Learn module.

## What's Included

The notes are designed to support both certification preparation and practical cybersecurity understanding.

Each module generally includes:
